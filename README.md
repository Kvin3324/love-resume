# LoveResume

Application Vue 3 / TypeScript / Tailwind pour créer un CV sentimental, sans stockage de données.

## Démarrage

1. `npm install`
2. `npm run dev`

## Fonctionnalités

- Saisie des relations passées, traits de personnalité, attentes, bio et références.
- Confidentialité : public, semi-privé, partage par lien.
- Export PDF via `window.print()`.
- Front-end moderne et responsive.
